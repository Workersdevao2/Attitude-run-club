Como trabalhar

  1. Edita produtos, zonas, textos ou imagens do site.
  2. Guardar rascunho — só neste telemóvel/computador (podes pré-visualizar a loja no mesmo browser).
  3. Publicar na loja — envia o catálogo para todos os visitantes (via Worker → Cloudinary).

Dicas mobile

  1. Os botões Guardar / Publicar ficam fixos em baixo.
  2. Usa “Carregar” ou “Escolher da média” — não precisas de colar URLs.
  3. Se algo falhar após publicar, contacta o programador.
